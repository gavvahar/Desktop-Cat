🐱 Desktop Cat
Features Download Instructions

A tiny pixel cat that lives on your desktop.

Free and open-source. Always-on-top, reacts to your mouse, keyboard, and scroll, and nags you to stretch, drink water, and take breaks. No accounts, no telemetry, no payments. Ever.

Get Desktop Cat All platforms

What it does

Reacts to you

  • Chases fast cursor movement, pounces on a sudden stop
  • Purrs when you gently move the cursor over its head
  • Pick it up and drag it around — squash, stretch, and wobble
  • Kneads while you type; overheats (and steams) if you type too fast
  • Unrolls like paper when you scroll

Keeps you on track

  • Stretch and drink-water reminders
  • Pomodoro focus/break timer with a floating countdown
  • Custom and pinned reminder messages
  • Falls asleep when you're idle, or during night hours you set

Make it yours

  • Pick a fur color and pattern
  • Give it a name, choose cat or puppy
  • Procedurally-synthesized sound cues, with a mute toggle
  • Settings saved locally — nothing ever leaves your machine

Extras

  • Feed it — a hunger meter that nags if you forget
  • Draws headphones on when you're playing audio
  • Steps aside during fullscreen video (X11)
  • Thinking-along / done-jump hooks for Claude Code, Codex, and Cursor

How to run it

🪟 Windows

Download Desktop-Cat-windows.zip, extract it, and run desktop-cat.exe from inside the extracted folder.

If Windows Defender or SmartScreen flags it: right-click the .exe → Properties → Unblock, or click "More info" → "Run anyway". It's unsigned (no code-signing certificate involved in this project) and unfamiliar to Windows, which commonly triggers that warning on its own.

🐧 Linux (AppImage)

Download Desktop-Cat-x86_64.AppImage, then:

chmod +x Desktop-Cat-x86_64.AppImage
./Desktop-Cat-x86_64.AppImage

No installation step — it's a single self-contained file, run it directly.

📦 Linux (Flatpak)

Download Desktop-Cat.flatpak, then:

flatpak install --user Desktop-Cat.flatpak
flatpak run io.github.gavvahar.DesktopCat

Drop --user for a system-wide install. Once installed, it also shows up in your desktop's app launcher as "Desktop Cat".

🍎 macOS

Download Desktop-Cat-macos.zip, unzip it, then right-click (not double-click) Desktop Cat.app → Open → Open. It's unsigned (no Apple Developer account involved in this project), so a plain double-click gets blocked by Gatekeeper.

Keyboard/scroll reactions additionally need Accessibility permission: System Settings → Privacy & Security → Accessibility → enable it for Desktop Cat. Without it, those reactions just silently don't fire — everything else still works.
